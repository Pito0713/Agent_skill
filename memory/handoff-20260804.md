## 重要決策

| 決策 | 選擇 | 原因 |
|------|------|------|
| 舊 `@` 路徑要不要遷移 7 個 repo | **整項刪除，不遷移** | 逐條 resolve 實測後只有 1 條真壞，且該專案已棄用。原 TODO 的「28 條命中」是 grep 計數不是損壞數 |
| Phase D 是否含 `entries/` 遷移 | **移出，併入 Phase A 相依** | 沒有 `rebuild-latest.sh` 就搬檔，`project-dashboard` 的 `find -name "latest.md"` 會當場找不到 |
| 交接檔 commit 由誰觸發 | **寫死在 `handoff` skill 內，絕不掛 git hook** | 自動寫入路徑是 ADR-014/015 明文禁止的，post-commit hook 就是這樣被廢的 |
| `~/.agent-sessions` 要不要裝 pre-commit-audit | **永遠不裝，也永遠不加 remote** | `> 路徑：` 欄位依設計含個人絕對路徑，與該 hook 的職責前提相反，裝了會擋掉每一次 commit |
| 舊 latest.md 缺 `寫入者` 欄要不要補 | **不補**，verifier 檢查限 `≥ 2026-08-04` | 補了就是猜，猜出來的身分比沒有更糟 |
| `project-context.md` 空占位 | **刪除並寫明「不要加回來」** | 被連續 4 份 handoff 誤掃成待辦（`20260702`/`0704`/`0706`/`0707`）|
| Phase A–C 做不做 | **暫緩，先留計畫** | 基率判斷（見上）。git 化已解掉唯一不可逆的風險 |
