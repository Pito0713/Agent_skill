## 重要決策

| 決策 | 選擇 | 原因 |
|------|------|------|
| B2 判斷結構 | 兩軸（寫回／下沉），不用三分 | 「已寫回」與「可下沉」不互斥；三分會讓已寫回文字的該下沉項被結案 |
| 驗收 B 層 | 真模型實跑（使用者選） | 假 claude 只驗得到 prompt 字串，驗不到語意 |
| 下沉欄填 script/test/cop | 也須寫「為什麼前面的層做不到」（使用者 11-23 裁決） | 與 enforcement-layers §3b 一致；11-23 起，不回補 |
| T5 規則措辭 | 「記進專案待辦」不寫「TODO.md」 | 下游不一定有 TODO.md（刻意偏離計劃書，已記 §5） |
| knowledge-grep 比對 | 改字面比對（`grep -F`） | `C++` 等詞不被當 regex；與舊版行為不同 |
| T4 verification recipe | 先不做 | 計劃書 Q2：上線兩週後看證據品質再決定 |
