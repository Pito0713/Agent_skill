## 重要決策

| 決策 | 選擇 | 原因 |
|------|------|------|
| 共用協定執行時讀不讀 | **內聯摘要，不讀共用檔** | 引用式要在執行時多讀一份共用檔，省下的體積等額付回，**單次呼叫幾乎不省**；被抽的段落多是「一行描述就能正確執行的格式」，不需逐字複製 |
| 兩段純冗餘（觸發詞列表、mentor 差異表） | **本次不動**（使用者裁決） | 縮小改動範圍。分析結果寫進 `_shared` §10 存檔，不隨對話消失 |
| `_shared/` 的定位 | **非 skill package** | 無 frontmatter / 無 SKILL.md，不進 index.json、不進路由表、不被 link farm 掛載 |
| frontmatter description | **一律不動** | §8.7 明訂由 `bin/gen-skill-frontmatter.py` 從 index.json 導出，禁止手改；也因此固定開場成本前後不變 |
| 版本列位置 | 追加到表尾 | 該表是舊→新排序（一度誤插在 v5.6 前，已修正） |

# 重算五份 mentor 的 token（bytes/3.5 之外的 CJK 加權口徑，僅供參考）
python3 - <<'EOF'
import glob
def est(p):
    s=open(p,encoding='utf-8').read()
    cjk=sum(1 for ch in s if '　'<=ch<='鿿')
    return round(cjk*0.9+(len(s)-cjk)*0.28)
for f in sorted(glob.glob("skills/learning/mentor-*/SKILL.md")):
    print(f"{est(f):>6}  {f}")
EOF
