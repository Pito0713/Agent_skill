## 已知問題 / 風險

- ⚠️ **委派 codex 一定要帶 `-c project_doc_max_bytes=0`**：否則被委派的 session 會繼承
  `~/.codex/AGENTS.md` 與 skill farm，把整個回合花在讀交接檔、載入 skill 的開工儀式上，
  **任務一個字都不做且 exit 0**。本輪連續兩輪失敗才查出來，已寫進 skill 全部七處指令。
  `--ignore-rules` 不是解方（只管 execpolicy `.rules`）。
- ⚠️ **`codex exec` 不吃 `--search`**（exit 2），網搜要用 `-c tools.web_search=true`。
- ⚠️ **macOS 沒有 `timeout` 指令**，別用它包裝 codex 呼叫。
- ⚠️ **codex 搜尋回來的內容會錯**：本輪實測一則模型清單答案與官方資料有出入。
  搜尋結果是線索不是結論。
- 🐛 **可能的同類問題**：本輪 11 條發現裡有 8 條性質相同——**靜默給出看似合理的錯數字**
  （NaN 繞過 `<= 0` 檢查、負數通過、缺鍵整筆消失、未知單位降級成計數單位）。
  `tw-stock-tracker` 用同一套「script 算數字、LLM 不心算」的職責切分，
  **那條規約只保證數字來自 script，不保證 script 的輸入驗證是對的**。值得去掃一次。
- ℹ️ `~/.agent-sessions/WakaWaka/latest.md` 的未提交變更**已由另一個 session 於本輪期間
  commit（`0b4241d`）**，該 repo 現在乾淨。前兩輪都記過這條，可以結案了。
