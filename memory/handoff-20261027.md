## 重要決策

| 決策 | 選擇 | 原因 |
|------|------|------|
| shopee | 不常駐 | 使用者決定；且是 dev server、launchd 讀不到 nvm PATH |
| 每週自動更新 | 不排 | 自動 git pull／rebuild 會撞上其他 harness 正在改的東西 |
| WakaWaka 自啟方式 | launchd 直接跑 binary、無 KeepAlive | start.sh 每次會改 `~/.claude/settings.json`；手動關掉不該被自動拉回 |
| SwarmTide 一鍵啟動 | 做在 FloatingAgenda 選單「快速啟動」，不借用排程列 | 借用排程列名不副實（會顯示「未載入」），使用者選正式功能 |
| 去背工具 | 不常駐 | 載入 1GB 模型吃記憶體，要用才開 |
