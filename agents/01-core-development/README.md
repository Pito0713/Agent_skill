# Core Development Agents

## 可用 Agents

| Agent | 觸發時機 |
|-------|----------|
| `api-architect.md` | 設計新 API、規劃 endpoint 結構、API 版本管理 |
| `backend-engineer.md` | 建立 server 應用、microservices、DB schema |
| `frontend-engineer.md` | 建立 UI 元件、響應式介面、無障礙設計 |

## 委派方式

```
在 CLAUDE.md 中：
"遇到 API 設計任務，委派給 agents/01-core-development/api-architect.md"
```
