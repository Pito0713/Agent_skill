# Wireframing

實作前用文字線框圖快速確認版面結構，避免做到一半才發現資訊層級錯誤。

## 執行步驟

[ ] Step 1：定義目標 - 這個頁面/畫面的主要用途是什麼？- 使用者來這裡要完成什麼任務？

[ ] Step 2：列舉必要內容 - 這個頁面需要哪些資訊區塊？- 哪些是主要內容，哪些是輔助資訊？

[ ] Step 3：安排版面模式（選一）

    | 模式 | 適用場景 |
    |------|---------|
    | Hero + 內容區 | 行銷首頁、產品介紹 |
    | 卡片網格 | 列表、商品頁、搜尋結果 |
    | 側邊欄 + 主內容 | 後台管理、文件、設定頁 |
    | 儀表板 | 數據總覽、監控頁面 |
    | 表單 | 登入、填寫、設定流程 |

[ ] Step 4：標註互動 - 哪些元素可點擊？點擊後發生什麼？- 有哪些狀態切換（loading / empty / error）？

[ ] Step 5：快速審查 - 最重要的資訊在視覺重心位置嗎？- 層級深度是否超過 3 層？

## 輸出格式

文字結構圖，例如：

```
┌─────────────────────────────┐
│ Header（Logo + Nav + CTA）   │
├─────────────────────────────┤
│ Hero（標題 + 副標 + 按鈕）    │
├──────────┬──────────────────┤
│ 側邊篩選  │ 商品卡片網格       │
│ (Filter) │ [卡片][卡片][卡片] │
└──────────┴──────────────────┘
```

標註互動點與狀態說明。
