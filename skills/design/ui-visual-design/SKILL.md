# UI Visual Design

根據產品定位快速鎖定視覺風格，給出可直接套用到 Tailwind / CSS 的方向。

## 執行步驟

[ ] Step 1：解析產品輸入 - 產品類型是什麼？（SaaS / 電商 / 工具 / 行銷頁）- 目標用戶輪廓？（工程師 / 消費者 / 企業 / 創作者）- 品牌關鍵詞？（專業 / 活潑 / 信任 / 創意）

[ ] Step 2：匹配風格（選 1 主 + 最多 2 備選）

    | 風格 | 適用產品 | 關鍵詞 |
    |------|---------|--------|
    | 科技極簡 | SaaS、開發工具 | 深色、無障礙、精準 |
    | 極簡黑白 | 作品集、設計工具 | 留白、對比、優雅 |
    | 自然有機 | 健康、食品、環保 | 暖色、圓角、柔和 |
    | 奢華編輯 | 精品、金融、法律 | 金色、襯線字、莊重 |
    | 賽博龐克 | 遊戲、NFT、科技感產品 | 霓虹、暗黑、衝突 |
    | 日式和風 | 冥想、文化、簡約生活 | 米白、墨色、靜謐 |
    | 玻璃擬態 | 現代 App、儀表板 | 模糊、透明、光感 |
    | 復古像素 | 獨立遊戲、懷舊品牌 | 8-bit、格線、限色 |

[ ] Step 3：產出視覺規格 - 主色 / 輔色 / 背景色（Hex 值）- 字型推薦（Google Fonts 優先）- 間距基準（4px / 8px grid）- 圓角大小（sharp / subtle / rounded）

[ ] Step 4：驗證 - 主色與背景對比度 ≥ 4.5:1（正文）- 風格是否符合目標用戶預期？

## 輸出格式

```
## 推薦風格：科技極簡

**理由**：開發者工具，用戶重視效率與可讀性

**視覺規格**
- 主色：#2563EB（藍）
- 背景：#0F172A（深藍黑）
- 文字：#F1F5F9
- 字型：Inter（內文）/ JetBrains Mono（程式碼）
- 圓角：4px
- 間距基準：8px grid

**備選**：極簡黑白 / 玻璃擬態
```
