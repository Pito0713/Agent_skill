# Design Patterns — ui-design-flow 查表

> 三個模式共用這份查表。SKILL.md 只放流程與判斷，模式選項與規格細節一律查這裡，
> 避免同一張表在多處各自漂移（原 information-architecture / wireframing / ui-visual-design 三份合併而來）。

---

## 模式 A 用：資訊架構

### A1. 架構模式（選一）

| 模式 | 特徵 | 適用場景 |
|------|------|---------|
| 階層式 | 樹狀，父子關係明確 | 大多數網站、後台管理 |
| 資料庫式 | 多維度篩選 | 電商、搜尋結果、內容平台 |
| 線性式 | 固定順序 | 表單流程、onboarding、教學 |
| 矩陣式 | 使用者自訂路徑 | 維基、知識庫 |

### A2. 層級規則（最多 3–4 層）

```
層級 1（全域導航）：5-7 項
層級 2（子導航）：每項下 3-6 項
層級 3（頁面內錨點）：非必要
```

### A3. 命名原則

- 使用使用者語言，不用系統術語
- 動詞開頭（「新增訂單」而非「訂單管理」）
- 名稱不重複、不歧義

### A4. 驗收問題

- 任何內容能在 **3 次點擊**內到達嗎？
- 命名是否讓初次使用者也能理解？

### A5. 輸出格式

```
首頁
├── 產品
│   ├── 所有產品
│   ├── 依類別瀏覽
│   └── 新品上架
├── 帳號
│   ├── 個人資料
│   ├── 訂單紀錄
│   └── 設定
└── 幫助中心
```

API 路由結構套用同一套規則，樹狀節點換成 endpoint 路徑段。

## 模式 B 用：版面骨架

### B1. 版面模式（選一）

| 模式 | 適用場景 |
|------|---------|
| Hero + 內容區 | 行銷首頁、產品介紹 |
| 卡片網格 | 列表、商品頁、搜尋結果 |
| 側邊欄 + 主內容 | 後台管理、文件、設定頁 |
| 儀表板 | 數據總覽、監控頁面 |
| 表單 | 登入、填寫、設定流程 |

### B2. 必標的三種狀態

`loading` / `empty` / `error`。**這三個沒標就是沒做完**——實作階段補這三個是最常見的返工來源。

### B3. 驗收問題

- 最重要的資訊在視覺重心位置嗎？
- 層級深度是否超過 3 層？

### B4. 輸出格式

```
┌─────────────────────────────┐
│ Header（Logo + Nav + CTA）   │
├─────────────────────────────┤
│ Hero（標題 + 副標 + 按鈕）    │
├──────────┬──────────────────┤
│ 側邊篩選  │ 商品卡片網格       │
│ (Filter) │ [卡片][卡片][卡片] │
└──────────┴──────────────────┘
```

標註互動點（哪些可點、點了發生什麼）與狀態說明。

## 模式 C 用：視覺規格

### C1. 風格對照（選 1 主 + 最多 2 備選）

| 風格 | 適用產品 | 關鍵詞 |
|------|---------|--------|
| 科技極簡 | SaaS、開發工具 | 深色、無障礙、精準 |
| 極簡黑白 | 作品集、設計工具 | 留白、對比、優雅 |
| 自然有機 | 健康、食品、環保 | 暖色、圓角、柔和 |
| 奢華編輯 | 精品、金融、法律 | 金色、襯線字、莊重 |
| 賽博龐克 | 遊戲、NFT、科技感產品 | 霓虹、暗黑、衝突 |
| 日式和風 | 冥想、文化、簡約生活 | 米白、墨色、靜謐 |
| 玻璃擬態 | 現代 App、儀表板 | 模糊、透明、光感 |
| 復古像素 | 獨立遊戲、懷舊品牌 | 8-bit、格線、限色 |

### C2. 規格產出項目

- 主色 / 輔色 / 背景色（Hex 值）
- 字型推薦（Google Fonts 優先）
- 間距基準（4px 或 8px grid）
- 圓角大小（sharp / subtle / rounded）

### C3. 驗收問題

- 主色與背景對比度 **≥ 4.5:1**（正文）——這是無障礙硬門檻，不是偏好
- 風格是否符合目標用戶預期？

### C4. 輸出格式

```
## 推薦風格：科技極簡

**理由**：開發者工具，用戶重視效率與可讀性

**視覺規格**
- 主色：#2563EB（藍）
- 背景：#0F172A（深藍黑）
- 文字：#F1F5F9
- 字型：Inter（內文）/ JetBrains Mono（程式碼）
- 圓角：4px
- 間距基準：8px grid

**備選**：極簡黑白 / 玻璃擬態
```
