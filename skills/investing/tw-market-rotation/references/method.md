| 方法 | 證據 | 本 skill 的用法 |
|------|------|----------------|
| 產業動能／相對強弱輪動 | ✅ 較強（Moskowitz & Grinblatt 1999，industry momentum） | 核心：RRG 近似象限 |

## 大盤量能狀態

| 指標 | 定義 |
|------|------|
| 量能比 `turnover_ratio` | 當日證券合計成交金額 / 近 20 日（含當日）平均 |
| 寬度 `breadth` | 上漲家數 / (上漲 + 下跌)，取「股票」欄（不含權證） |
| `breadth_5d` | 寬度 5 日平均 |

| 狀態 | 條件（依序判定） | 常數 |
|------|------------------|------|
| 不足 | 量能比 < 0.8 **或** 5 日寬度 < 0.4 | `WEAK_TURNOVER_RATIO` / `WEAK_BREADTH` |
| 充足 | 量能比 ≥ 1.1 **且** 5 日寬度 ≥ 0.5 | `STRONG_TURNOVER_RATIO` / `STRONG_BREADTH` |
| 普通 | 其餘 | |
| NULL | 不足 20 個交易日，或窗口內有缺值 | |

「不足」先判定：量縮或多數股票下跌時，單邊條件就足以讓量能不可信；
「充足」則要求量與寬度同時成立，避免少數權值股放量拉抬被誤判為資金全面進場。

## 類股輪動

### 成交比重變化

`share = 類股成交金額 / 大盤證券合計成交金額`，`share_delta = 5 日均 share − 20 日均 share`。
報告以百分點（pp）顯示。正值 = 資金近期流入該類股。

### RRG 近似

```
RS          = 類股指數收盤 / 加權指數收盤
RS-Ratio    = 100 × RS / SMA(RS, 20)
RS-Momentum = 100 × RS-Ratio / RS-Ratio(5 個交易日前)
```

| 象限 | RS-Ratio | RS-Momentum | 解讀 |
|------|----------|-------------|------|
| Leading | ≥ 100 | ≥ 100 | 相對強且仍在加速 |
| Weakening | ≥ 100 | < 100 | 相對強但動能轉弱 |
| Lagging | < 100 | < 100 | 相對弱且仍在減速 |
| Improving | < 100 | ≥ 100 | 相對弱但動能轉強 |

需 25 個交易日（20 + 5）才有象限，不足寫 NULL。

⚠️ **這是 JdK RRG 的近似**：Julius de Kempenaer 的原始 RS-Ratio / RS-Momentum 公式未公開，
本實作數值**不會**與 StockCharts 等商業版本一致，只保證象限方向的語意相同。

- **排除母類股**：「電子工業類／電子類」「化學生技醫療類」包含子類股，
  以及 MI_INDEX 的綜合分類（水泥窯製、塑膠化工、機電）——放進排名會重複計算成交比重。

- 代碼 ↔ 指數名稱對照在 `scripts/sectors.py`，兩個資料源命名不一致
