# 台股進場評分與 Track Record 追蹤

> **這個 skill 不提供投資建議。** 它只描述技術面狀態、記錄判斷、事後對帳。
> 概念層的投資教育（行為偏誤、資產配置原則）走 `skills/learning/mentor-invest/SKILL.md`。

---

## 職責切分（不可違反）

| 誰做 | 做什麼 |
|------|--------|
| **Script（確定性）** | 抓價、算指標、六維評分、進場區間、停損、報酬、命中率、校準度 |
| **LLM（你）** | 解讀分數、寫 thesis、質性檢討上次論點、提醒 base rate |

**LLM 絕不自行生成任何價格、分數、報酬率或命中率。** 這些數字只能來自 script 輸出。
若 script 失敗或資料不足 → 據實回報失敗，不得憑記憶補一個看起來合理的數字。

---

## 環境

- 資料庫：`~/.stock-tracker/tracker.db`（SQLite，不進本 repo）
- 相依：Python 3 標準庫，無需 pip 安裝
- 資料源：TWSE（上市）與 TPEx（上櫃）盤後開放資料，免金鑰；市場別由實際查詢判定

執行目錄一律為本 skill 的 `scripts/`。

## 模式 1：分析（使用者問某檔的進場點位／評分）

```bash
cd skills/investing/tw-stock-tracker/scripts
python3 track.py record <代號> --horizon 30 --thesis "<你寫的判斷摘要>"
```

`record` 會自動抓最新資料與當日估值、評分、落一筆 `open` 預測，並回傳完整 JSON。
JSON 的 `valuation` 是本益比／淨值比／殖利率與「相對該股自身近 3 年」的百分位，
**只附帶顯示、不影響分數**。轉述時只說「在自己歷史的第幾百分位」，不得說成貴或便宜、該不該買。

**執行前**：先問使用者時間框架（horizon，預設 30 天），因為它決定何時對帳。
**執行後**：照 `references/output-format.md` 呈現，thesis 需在看到評分結果後再寫。

若使用者只想看評分、不要落記錄 → 先抓資料再評分：

```bash
python3 fetch_twse.py <代號>      # 上市／上櫃自動判定，落庫並還原除權息
python3 fetch_valuation.py latest <代號>   # 選用：補當日估值，不跑則估值顯示無資料
python3 score.py <代號> --json
```

`score.py` 只讀本地 DB、不會自行抓資料；跳過 fetch 會報「僅 0 根日線」（首次查詢）
或拿舊資料評分（曾查過的標的）。`record` 內建抓取，不需此步。

## 模式 2：對帳（使用者再次詢問同一標的，或主動要求對帳）

```bash
python3 track.py reconcile
```

**使用者第二次問同一檔時的正確做法**（重要，避免過度宣稱）：

1. 跑 `reconcile`，讓到期的舊預測結案
2. 撈出該標的上一筆預測，做**質性兌現檢討**：上次的論點兌現了嗎？進場區間有觸及嗎？
3. 跑模式 1 產生本次新判斷

**必須說清楚**：這次判斷變準是靠**今日更新的真實資料**，不是靠上一筆記錄。
單一筆過往預測在統計上不能拿來算準確率——n=1 沒有意義。

## 模式 3：報告（使用者問「我準不準」）

```bash
python3 track.py report
```

輸出命中率、按分數分層的校準度、各維度預測力。

**解讀規則**：
- 樣本 < 30 筆 → 必須明講統計上不具意義，不得下「你很準／不準」的結論
- 真正的價值是**校準度**（高分區是否真的比較準），不是單純命中率——命中率會被大盤多空整體帶著跑
- 各維度預測力長期為負者 → 提議調降該維度權重（見 `references/scoring-rubric.md`）
- 報告末段「訊號門檻」顯示目前門檻版本與距校準樣本門檻的進度

### 校準訊號門檻（使用者問「門檻要不要調」或報告顯示已達樣本門檻）

```bash
python3 track.py calibrate          # 只出提案，不寫入
python3 track.py calibrate --apply  # 使用者明確同意後才執行
```

用已對帳樣本重挑偏多／偏空門檻（候選 50–75／25–50，步距 5）。依時間切前 70% 挑、
後 30% 驗，前段中對帳期間跨進後段者剔除。需已對帳 ≥120 筆**且**涵蓋 ≥12 週才會執行；
後段偏多、偏空各需 ≥15 筆，且必須同時贏過「全判偏多」與目前門檻，結論才是「建議採用」。

**不得未經使用者同意就加 `--apply`**。提案結論不是「建議採用」時 `--apply` 會被拒絕，
這是預期行為，照實回報理由，不要改參數重跑來湊出通過。

## 模式 4：回測（使用者想看「這套評分過去表現如何」「中短期趨勢」）

```bash
python3 backtest.py run --years 3      # 首次約 2 小時（含法人逐日回補；TWSE 請求間隔 3 秒），之後只補新的月份與交易日
python3 backtest.py report             # 加 --horizon 7|14|30 切換逐季趨勢用的期間
```

每週最後一個交易日只用當天以前的資料評分，再用之後 7／14／30 天的還原價對帳。
報告：各分數區間的上漲比例、平均／中位數報酬、相對全部平均；高分組 − 低分組（全期混合與同週比較）；
可成交口徑（次一交易日開盤進場、扣手續費與證交稅、開盤漲停買不到／跌停鎖死賣不掉）；
Rank IC（總分與六分項，附依重疊修正的 t 值）；逐季同週比較與平均 IC。
評分只讀評估日以前的日線與當時已核准的門檻。`--fee-discount 0.6` 可設券商手續費折扣（預設不打折）。
結果存 `backtest_*` 表，**不進 predictions、不餵 calibrate**。單一標的失敗會略過並列在報告開頭。

**解讀規則**：
- 一定要轉述報告開頭的警告：標的是現在挑的（選股偏差）、相鄰週報酬窗口重疊，結果偏樂觀
- 以 **Rank IC 的 t 值**為主：|t| < 2 必須說「無法和運氣區分」；看可成交口徑（扣成本後）而非收盤口徑
- 分項 Rank IC 是調整權重的依據，但 6 分項 × 3 期間同時檢定，單一 |t|≥2 可能是巧合——
  要跨期間一致（如 7 天與 14 天都顯著）才值得提議調權重，且調整仍須使用者同意
- 同週比較與逐季表輔助判斷穩定性；樣本 < 5 的區間報告本身就不給數字
- 未排除個股組成差異，也不含最低手續費 20 元——不得說成「已證實有效」
- 回測是歷史重演，不得說成「這檔接下來會漲」
- 「法人因子 Rank IC」：外資、投信近 5／20 日淨買超 ÷ 成交股數，**4 個因子在回測前就鎖定，不得事後增刪或改窗口**。
  有效的條件同 rubric 調權重前提：兩組獨立標的（如自選股與臺灣 50）同號且 |t|≥2、前後兩半同號；
  只有單一 run 顯著就說「待另一組標的驗證」。即使有效也**不進評分**，要納入須使用者另行裁決。
  法人資料由 `run` 自動回補（全市場逐日，首次約 75 分鐘），也可單獨跑 `fetch_flows.py backfill`
- 報告末段「技術分 × 本益比百分位」：估值歷史由 `run` 自動回補（全市場、每週一天，首次約 20 分鐘）。
  格子未控制大盤時點，只能當線索，不能當「低本益比加高分比較好」的證據

## 已知限制（回答時必須誠實揭露）

1. **盤後資料**：TWSE／TPEx 開放資料皆為盤後，非盤中即時報價。
2. **除權息還原的資料來源**：上市股未來約 5 週用預告表（`TWT48U_ALL`），
   更早的由除權除息計算結果表（`TWT49U`）以「前收 − 官方參考價」反推補齊（`source = TWT49U`），
   `sync_ticker` 遇到金額未知的除權息日會自動補。兩表都查不到者（如減資）仍標
   `has_unadjusted_exdiv`——旗標出現時要主動說明。
   **上櫃股不受此限**：TPEx 的「漲跌」是對除權息參考價計算的，回溯窗口內的
   除權息金額都反推得出。但那是**推論值而非官方公告金額**，揭露時要說明來源
   （`dividends.source = TPEX_IMPLIED`）。
3. **持有期間跨未知除息** → 預測自動標 `needs_review`，不計入統計。
4. **總分沒有可證實的預測力**：自選 21 檔與臺灣 50 成分股的 3 年回測，總分 Rank IC 皆無法和運氣區分，
   分項訊號換一組標的就變號（見 `references/scoring-rubric.md`「回測證據」）。呈現評分時必須說明
   它是「技術面狀態描述」，不得暗示高分代表較可能上漲。權重經使用者裁決暫不調整；
   門檻可用 `track.py calibrate` 校準，但同樣受此限制。
5. **估值只記錄、不評分**：百分位需該股至少 1 年的週估值歷史（先跑
   `fetch_valuation.py backfill`，或跑一次回測），不足就不給。虧損股沒有本益比，ETF 沒有估值。
   上市資料附計算所用財報季別，上櫃沒有。
   **未還原旗標只看最近 120 根**：更早的未知除權息不再標記；長期極低波動的個股，
   窗口外的缺口仍可能影響 RSI 分數（殘留風險，見 `score.py` FLAG_WINDOW_BARS 註解）。
6. **無出場規則**：script 只推導進場區間與停損，不產生目標價或出場價。
   被問出場點位時，只能講停損與既有指標價位（如 60 日高），不得自行生成目標價。
