# 台股六維評分 v1

> **權重是假設，不是定論。** 以下配分依台股特性擬定，無實證基礎。
> 累積 30 筆以上對帳樣本後，用 `track.py report` 的「各維度預測力」回頭校準。
> 正本定義在 `scripts/score.py`，本檔說明「為什麼這樣配」。

---

## 配分總表（滿分 100）

| 維度 | 配分 | 與參考基準的差異與理由 |
|------|------|----------------------|
| 趨勢 | 25 | 由 30 降至 25。台股受外資流向主導，單純均線趨勢的預測力被稀釋 |
| 乖離率 | 20 | 維持。**進場點位任務的核心**：適度負乖離＝回檔到位，正乖離過大＝追高 |
| 支撐/壓力 | 15 | 由 10 升至 15。距支撐多近直接決定風險報酬比，對進場決策比對方向更重要 |
| 量能 | 15 | 維持 |
| MACD | 15 | 維持 |
| RSI | 10 | 維持 |

## 各維度計算

### 趨勢（25）— 加總制
- 收盤 > MA20：+10
- MA5 > MA20：+8
- MA20 > MA60：+7

### 乖離率（20）— `bias = (收盤 − MA20) / MA20 × 100`
| bias 區間 | 分數 | 意義 |
|-----------|------|------|
| −3 ~ 0 | 17 | 略低於均線 |
| −8 ~ −3 | **20** | 回檔到位，最理想進場 |
| −12 ~ −8 | 14 | 跌較深，需留意基本面 |
| < −12 | 8 | 超跌，風險升高 |
| 0 ~ 3 | 12 | 略高於均線 |
| 3 ~ 8 | 7 | 偏高 |
| 8 ~ 15 | 3 | 明顯偏高 |
| > 15 | 0 | 追高 |

### 支撐/壓力（15）= 貼近支撐（10）+ 上檔空間（5）
- 距 60 日低點：≤5% → 10；≤12% → 8；≤25% → 5；≤40% → 2；其餘 0
- 距 60 日高點空間：≥15% → 5；≥8% → 3；≥3% → 1；其餘 0

### 量能（15）— `ratio = 當日量 / 20 日均量`
| 情境 | 分數 |
|------|------|
| 價漲量增（ratio > 1.2） | 15 |
| 價漲量平（0.8 ≤ ratio ≤ 1.2） | 11 |
| 價跌量縮（ratio < 0.8）＝健康回檔 | 11 |
| 價平 | 8 |
| 價漲量縮＝背離 | 6 |
| 價跌量增＝賣壓 | 2 |

### MACD（15）
| 狀態 | 分數 |
|------|------|
| DIF > DEA 且 DIF > 0（零軸上金叉） | 15 |
| DIF > DEA 且 DIF ≤ 0（零軸下轉強） | 11 |
| DIF ≤ DEA 且 DIF > 0 | 6 |
| DIF ≤ DEA 且 DIF ≤ 0 | 0 |

### RSI(14)（10）
| 區間 | 分數 |
|------|------|
| 40 ~ 60 | 10 |
| 30 ~ 40 | 9 |
| 20 ~ 30 | 7 |
| 60 ~ 70 | 6 |
| < 20 | 5 |
| 70 ~ 80 | 3 |
| > 80 | 0 |

## 硬規則（觸發即壓制，防止評分把高風險狀態講成好進場點）

| 規則 | 效果 |
|------|------|
| RSI > 80 | 分數壓至 59（中性上限） |
| 正乖離 > 15% | 分數壓至 59 |
| 當日最高價 ≥ 前收 × 1.095（觸及漲停） | 不提供進場區間（漲停流動性失真） |
| 當日量 < 20 日均量 × 50% | 訊號降一級 |
| 日線不足 60 根 | 拒絕評分，不出半套判斷 |

## 進場區間與停損（規則推導，LLM 不得自行生成）

```
進場區間 = MA20 ± 0.5 × ATR(14)
停損     = 進場區間下緣 − 2 × ATR(14)
```

**為何錨點是 MA20 而非「MA20 與支撐取較低者」**：
實測發現 MA20 幾乎恆大於 60 日低點，取較低者會讓錨點永遠落在 60 日低點，
進場區間遠離現價（實測 2330 差距達 12%）而失去參考價值。
改為兩個價位各司其職——MA20 當回檔進場錨點，ATR 決定停損距離，60 日低點僅作為支撐維度的計分依據。

另輸出 `entry_status`：現價落在區間內／偏高／偏低。
