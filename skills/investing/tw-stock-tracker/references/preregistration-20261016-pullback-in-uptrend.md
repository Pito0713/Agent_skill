# 預先登錄：多頭回檔假設（2026-10-16）

> 狀態：**已凍結（2026-10-20 使用者確認）**。之後才抽樣、跑回測；結果出來前不得改本檔的任何條件。
> 依據：ADR-026 的調權重門檻（兩組獨立標的同號且 |t|≥2、前後兩半同號、在未參與挑選的資料上有效）。

## 1. 為什麼要測

v1 的六個分項分成兩派：趨勢、MACD 獎勵上漲（順勢），乖離、支撐、RSI 獎勵下跌（逆勢）。兩派常互相抵消，
總分在 7／14／30 天都和運氣分不開。乖離換一組標的就變號；支撐滿分（貼近 60 日低點）在兩組回測都表現最差。

v1 原意是「多頭回檔進場」，但乖離與支撐的計分**不看趨勢**——空頭裡的下跌也拿回檔滿分。
本假設檢驗：**回檔分數只在多頭時才有預測力**。

## 2. 已看過的資料（揭露，避免假裝沒看過）

- 已看過：run 1（自選 21 檔）、run 2（臺灣 50）的總分與分項 Rank IC，以及乖離、支撐各得分組的同週超額報酬（不分趨勢）
- **未看過**：依趨勢拆開後的任何數字。本檔凍結前不計算

## 3. 假設與定義

- **多頭**：評估日 MA20 > MA60。由已存的 `s_trend` 反推（含 7 分那一項者：`s_trend ∈ {7, 15, 17, 25}`），不需改程式
- **回檔分數**：`pullback = s_bias + s_support`（v1 原配分，不重新設計門檻）
- **H1（主假設）**：在多頭樣本中，`pullback` 與可成交報酬的 Rank IC 為正
- **H2（附帶，只記錄）**：在非多頭樣本中，`pullback` 的 Rank IC ≤ 0 或不顯著
- **v2 總分**：多頭時與 v1 相同；非多頭時乖離固定 10 分、支撐固定 7 分（約各自滿分的一半——不獎勵也不懲罰空頭回檔，
  避免改動變相放大趨勢權重）。v1、v2 都用**六項原始加總**比較，不含硬規則壓分，兩者口徑一致

## 4. 樣本

- **樣本外標的（新）**：從 `stock_names` 抽 60 檔普通股（4 碼數字、首碼非 0，即排除 ETF），
  排除 run 1、run 2 已用過的 70 檔；上市、上櫃都抽。亂數種子 `20261016`，用 Python `random.Random(20261016).sample`，
  候選清單依代號排序後抽
- 抓取或評分失敗者直接略過、**不補抽**；有效標的少於 40 檔 → 本次判定「樣本不足」，不下結論
- **期間**：與 run 1、2 相同的 3 年（2023-10 ~ 2026-10），每週一次。前後兩半以樣本中位評估日切分
- **主要期間**：持有 14 天、可成交口徑（次日開盤進場、扣成本）。7 天、30 天只記錄，不參與判定

## 5. 判定標準（全部滿足才算通過）

1. 新標的，多頭樣本，`pullback` Rank IC **t ≥ +2**（t 值用既有的重疊修正）
2. 新標的的前後兩半，該 IC 都為正
3. run 1、run 2 至少一組在多頭樣本中 t ≥ +2，且**沒有任何一組 t ≤ −2**
4. 新標的上 **v2 總分** Rank IC 的 t ≥ +2，且高於 v1 總分

- 1–3 通過、4 未過 → 條件化只用於顯示（例如「空頭中的回檔不列為進場點」），不改總分
- 1–3 任一未過 → 假設不成立，維持 v1（ADR-026）

## 6. 不論結果都要做

- 結果寫進 `scoring-rubric.md` 的回測證據段、ADR，未通過也要記
- **不在同一批資料上試第二個變體**（改門檻、改定義、改中性值）。新想法要重新登錄，並換一組沒用過的標的
- 已知限制：期間與 run 1、2 重疊（只有標的是樣本外，時間不是）；抽樣用的是**現在**仍掛牌的股票，有存活者偏差

## 7. 執行（凍結後）

1. commit 本檔
2. 依 §4 抽樣，把清單附在本檔末尾（另一個 commit）
3. `python3 backtest.py run --years 3 --tickers <清單>`（逐月抓日線，每次間隔 3 秒，預估 2 小時以上，只在資料主機執行）
4. 依 §3、§5 計算並回報；分析 script 放 scratchpad，不進 repo
