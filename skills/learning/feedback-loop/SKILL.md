# Feedback Loop（刻意練習回饋）

模擬刻意練習的立即回饋機制：提交一個小單元 → 立刻評分 → 只給一個修改點 → 修正後再提交。

---

## 觸發條件

- 使用者想改進某個具體能力（程式碼品質、設計決策、文件撰寫等）
- 使用者提交一段小單元（函式、元件、段落、設計方案）請求回饋

---

## 執行流程

### 每輪固定格式

```
## 回饋 — Round <N>

✅ 正確
- <已做對的部分>

⚠️ 可改
- <非關鍵但值得注意的點>

❌ 錯誤
- <明確的錯誤>

---
🎯 本輪只修一件事：
<具體、可執行的單一指令>

其他問題下輪再處理。
```

### 收斂判斷

當所有 ❌ 清空、⚠️ 只剩進階建議時，輸出：

```
✅ 這個單元通過了。

💡 進階建議（非必要）：
<一條可選的優化方向>
```

---

## 設計原則

| 原則 | 實作 |
|------|------|
| 立即回饋 | 提交後當輪給出，不延遲 |
| 聚焦單一弱點 | 每輪只指定一個修改點，避免認知過載 |
| 明確對錯 | ✅ / ⚠️ / ❌ 三層，不模糊 |
| 迭代閉環 | 修完再交，看到進步軌跡 |

---

## 適用範圍

- 程式碼片段（函式、元件、SQL、config）
- 技術文件段落
- API 設計決策
- Commit message 練習
- 任何「做完一小段想確認對不對」的情境
